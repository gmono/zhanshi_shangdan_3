# Windows 与 iOS 平等双向同步实施计划

**目标：** Windows 继续提供同步及图片服务，Windows 触摸屏和多个 iOS 共用同一份页面、相机及分割线状态，任一端操作均同步到其他端。Windows 不增加操作按钮。

**实施约束：** 仅修改 `fix` 分支；保留开始时已有的 `.gitignore` 改动；不修改资源命名、发现协议、端口或安装包；遵守用户要求，不运行测试、不启动浏览器或模拟器。本次仅进行源码核对与编译检查，不能据此宣称真机联动已验收。

**方案：** 沿用现有 WebSocket 母线及字段级补丁。Windows 与 iOS 角色只区分界面和连接地址，不再区分写权限。服务器按收到顺序合并、递增 `revision`，向其余连接广播完整状态，向发送端返回 `state_ack`。客户端接收状态不重新发布，保留本机在途补丁直到服务器确认；没有主控锁，也不添加定时全量广播。
