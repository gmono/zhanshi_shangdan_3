# 安装目录原图与 iOS 加载验证计划

按实现计划、测试驱动开发和完成前验证流程，在当前修复分支执行；保留其他 AI 尚未提交的文档修改。

## 验收目标

- Windows 直接读取安装目录下的 `地图资源/`，按现有中文文件名识别网盘原件，不裁剪、配准、改色、覆盖原图。
- 自动生成的 Zoomify 缓存仅保存在 `.cache/`；同名原图更新后必须重建，旧预览缓存不能冒充原图。
- 每张图保留自己的实际宽高，年份图片尺寸不同时仍能展示。
- iOS 未连接时不加载地图；连接后等待真实目录和瓦片，Windows 准备期间持续重试，按目录自动发现图1至图10并同步相机。
- GitHub CI 分别验证 Windows 原生资源服务、WebKit 控制端和真正的 iPad 模拟器界面；测试图片临时生成，不能进入成品或充当客户原图。
