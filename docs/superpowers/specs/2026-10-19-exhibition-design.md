# 展厅双端地图基础设计

基于 rgilsimoes/Tauronic 原始模板，保留 Tauri 2、Ionic React、TypeScript 和 Vite。Windows 是只读展示端，iOS 是完整操作端；共享地图模型与渲染组件，按原生操作系统分流，不按窗口宽度推断权限。浏览器用 ?role=controller 或 ?role=display 预览。

## 地图与手势

采用 OpenLayers。标准地理地图默认 EPSG:3857、XYZ 瓦片、多级缩放、视口加载及有界缓存。初始提供 OSM 在线地图用于验证，不将其当作离线交付地图。通过环境变量更换自有 XYZ 服务。大幅展厅平面图提供 Zoomify 图像金字塔接入，使用像素投影与原图尺寸，避免把平面图误投影到地球坐标。

iOS 使用 OpenLayers 默认 DragPan、PinchZoom、DoubleClickZoom，关闭旋转以保持大屏方向稳定。Ionic 内容层关闭滚动，地图容器 touch-action:none，操作面板独立滚动。Windows 不接受地图拖动或编辑，只消费展示状态。OpenLayers 的普通瓦片层使用 Canvas 渲染，后续大量矢量数据可升级专用 WebGL 图层；不预先声称所有图层均为 WebGL。

## 双端同步

附带独立 Node WebSocket 中继，用房间密钥隔离，控制端写入中心点、缩放级别和图层可见性，大屏只读订阅。服务端验证角色与状态，拒绝展示端写入；每房间只允许一个控制端，断线后自动重连并恢复快照。iOS 根据地图视角变化持续同步，每 16ms 合并一次相机与卷帘状态，结束时保留最终状态。当前不做设备发现、多控制端协同或离线地图下载器。

## 验收边界

验证前端类型、生产构建、状态校验、房间同步及浏览器双角色联动。浏览器触摸模拟用于检验平移与缩放，原生 iOS 手感须在 macOS/Xcode 和真实设备验证；Windows 安装包在 Windows 构建。Linux 不声称已完成原生 iOS 或 Windows 编译。

## 补充：三图卷帘对比

新增普通地图与三图对比两个视图。三张地图叠放、共享同一个 OpenLayers View，用两条垂直分割线及 clip-path 裁剪三个可见区域。拖动分割线不改变相机，平移或缩放任意可见地图时三图保持严格对齐。控制端可触摸拖动两条分割线，大屏只读同步。分割比例、对比模式与相机一起进入状态快照；限制分割范围及最小间距，窗口尺寸改变仍按比例保持位置。演示用三种在线底图；正式对比需同投影、同配准的三期/三类 XYZ 或 Zoomify 瓦片。

## 最终导航约定

三图卷帘对比是软件主屏，普通地图为子界面。iOS 通过按钮进入普通地图，点击返回或浏览器后退回到三图主屏；Windows 跟随当前界面与状态。浏览器角色切换仅用于开发，原生 iOS 和 Windows 自动识别角色。
