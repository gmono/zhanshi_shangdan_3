# 技术架构

## 技术选型

采用 Tauronic 的 Tauri 2 + Ionic React + Vite，地图采用 OpenLayers，状态同步采用 WebSocket。原模板来源及许可证保留。

## 模块

src/platform：原生系统识别；src/map：地图源、相机状态、渲染与手势；src/sync：共享校验协议与客户端；server：只保留内存快照的房间中继；src/App.tsx：组装双端；src/components：操作面板。

## 地图数据

XYZ 地理地图与 Zoomify 像素地图通过环境配置二选一。两端必须使用同一份地图配置。大型图像必须预切片，禁止单张巨图全量加载。跨域地图服务需 CORS；离线可将瓦片部署于展厅局域网服务。

## 同步接口

连接查询参数 role 为 controller 或 display、room 为共享密钥。控制端发送经验证的 state，服务端赋予递增 revision 并广播 snapshot；display 的写入被拒绝。消息长度、字段范围、房间数量与连接数量有限制。生产环境使用 WSS 和高熵房间密钥，中继只用于受控展厅网络。

## 原生构建

Windows 在 Windows 构建 MSI/NSIS；iOS 在 macOS 安装 Xcode、配置签名后初始化和构建。CI 提供 Windows 构建验证；iOS 手势需真实设备验收。

## 三图实现

三个 OpenLayers Map 共享一个 View，容器保持全尺寸，仅裁剪可见区域。两个分割线以归一化比例表示，避免缩小地图容器造成地图中心漂移；用指针捕获处理拖动，限制频率同步。对比数据必须地理/像素配准，开发用在线样式差异底图验证。
