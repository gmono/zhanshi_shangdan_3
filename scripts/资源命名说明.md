# 客户原始图片放置

在 Windows 安装目录内的 `地图资源` 文件夹放入图片，文件夹与 `tauronic.exe` 同级。地图对比图使用固定的 `左屏`、`中屏`、`右屏` 三个文件夹；每个文件夹内放 `1`、`2` 两张原图，`1` 代表左侧图片，`2` 代表右侧图片。大图文件按 `图1.jpg`、`图2.jpg` … 顺序自动发现，最多 `图10.jpg`，至少需要 `图1.jpg`。不需要提前缩放、裁剪、改色或配准。

地图资源/图1.jpg … 地图资源/图10.jpg（按实际数量放置）

- 文件夹和编号是硬约束：`左屏`、`中屏`、`右屏` 及其中的 `1`、`2` 必须存在；大图按连续编号自动发现，最多十张，缺少图1或中间断号会报错。
- 图片扩展名支持 png、jpg、jpeg、tif、tiff、webp、bmp；程序按编号读取原图，不按文件内容去重。
- 同文件夹中的 TIF 和 OVR 原件保留，程序直接使用网盘下载的原始 PNG，不生成替代 PNG、不覆盖原件。年份图片尺寸不同时，各自按实际尺寸显示。
- Windows 程序内置图片服务，启动后处理原图；原图不修改，不进入安装包。iOS 连接 Windows 后读取瓦片；未连接显示遮罩，点击进入设置。
- `原图/` 仅保存原始文件副本，程序不会读取，也不会对图片做任何处理；程序只读取上面的固定文件名并切片。
- `.cache/` 由 Windows 程序自动生成，仅存储显示所需的 Zoomify 瓦片。替换同名原图后重启程序，文件大小或修改时间变化时会重新生成；旧的无来源记录预览缓存不会被当作原图缓存复用。
- 首次切片期间 iOS 显示准备状态并自动重试。Windows 就绪后，iOS 从 Windows 读取真实图片尺寸和瓦片；原始巨图不会发送给 iOS 整图解码。
