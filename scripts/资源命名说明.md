# 客户原始图片放置

Windows 程序旁或文档目录的 展厅App 内放置 地图资源 文件夹。直接放入下载的 序厅-遥感图 整个文件夹；同时把 456.jpg 复制成图1.jpg至图5.jpg。五个大图文件名固定为图1至图5，不能改名。

- 文件名是硬约束：三个地点、每地点两年、五个大图都必须使用上面的固定文件名；缺一个就报错，不能改名。
- 图1.jpg至图5.jpg 是 456.jpg 的五个副本；程序按文件名分别处理和缓存，不使用哈希去重。
- 同文件夹中的TIF和OVR原件保留，程序使用已配准PNG。
- Windows 程序内置图片服务，启动后处理原图；原图不修改，不进入安装包。iOS 连接 Windows 后读取瓦片；未连接显示遮罩，点击进入设置。
